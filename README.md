A **Sales Prediction** capstone project for the Rossmann drug store chain — forecasting daily sales for 1,115 stores across Germany using historical sales data, promotions, and store metadata.

## 🎯 Problem Statement

Predict future daily sales for Rossmann stores up to 6 weeks in advance, helping the business plan inventory, staffing, and promotions effectively.

## 🏗️ Approach

- **Exploratory Data Analysis** — Trends, seasonality, store patterns
- **Feature Engineering** — Date features, lag features, rolling averages
- **XGBoost / Random Forest** — Ensemble models
- **Time Series Analysis** — Seasonality decomposition

## ✨ Features

- 📈 Multi-store sales forecasting (1,115 stores)
- 📅 Time series feature engineering
- 🏪 Store type & assortment analysis
- 🎯 Promotion and holiday impact analysis
- 📊 RMSPE evaluation metric
